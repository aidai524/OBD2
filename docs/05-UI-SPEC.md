# 05 · UI/UX 规格

> 版本：v1.1 · 状态：V1 基线已冻结 · 读者：Codex（实现 Flutter Widgets）+ 设计参考
> 设计原则：极简（对比 Torque Pro）、新手友好、行动导向

**版本边界**：本文件描述完整产品蓝图；未特别标注的 P1–P12 页面属于 V1。自定义仪表盘、数据录制、适配器商城引导、单次解锁属于 V1.1；社区与推荐奖励属于 V2。

**文案边界**：本文中的中文按钮/提示是行为说明；V1 实际界面只交付审核后的 `en-US` 文案。

## 1. 导航结构

**底部 Tab（5 个）：**

| Tab | 页面 | 对应功能 |
|---|---|---|
| 车库 Garage | 车辆列表 + 当前车辆概览 | F-D |
| 诊断 Diagnostics | 连接 → 读码 → 结果 | F-A / F-B |
| 数据 Live Data | 实时仪表盘 | F-B-04/05 |
| 历史 History | 诊断历史 | F-C-04 |

**顶层流程**：诊断结果 → AI 解读（订阅拦截）→ 报告导出。

## 2. 页面清单

### P1 · 启动/引导（Onboarding）
- 3 屏引导：① 连接适配器 ② AI 解读故障码 ③ 维修费用估算（不是维修厂报价）
- 登录/注册入口（邮箱/Apple/Google，F-E-01）
- 跳过引导：创建 Supabase 匿名会话，游客可使用本地免费功能及 1 次完整 AI 体验；后续绑定邮箱/Apple/Google 时合并到同一用户
- V1 首次安装离线时停留在可恢复的初始化状态，解释“需要联网一次建立安全本地档案”；身份和加密库初始化成功后，后续本地诊断可离线

### P2 · 车库（Garage）
- 车辆卡片列表（品牌/型号/年份/用户录入里程；未知时显示“未填写”）
- 空状态："添加第一辆车"
- 点击车辆 → P3 车辆详情
- 添加车辆：VIN 自动解码 + 手动补全（F-B-08 / F-D-02）
- Free 用户第 2 辆车触发 Pro paywall

### P3 · 车辆详情（Vehicle Detail）
- 车辆信息卡（含 VIN 解码结果）
- 快捷入口：诊断 / 实时数据 / 保养 / 历史
- 保养提醒卡片（Pro，F-D-04）

### P4 · 连接页（Connection）
- 三选一连接方式：WiFi / BLE / 蓝牙经典（F-A-01）
- 平台矩阵：iOS 支持 WiFi/BLE；Android 支持 WiFi/BLE/蓝牙经典 SPP，iOS 不展示 SPP
- WiFi：引导连适配器热点 → 输入 IP/端口
- BLE：扫描设备列表 → 点击连接
- 蓝牙经典（Android）：已配对设备列表
- V1：连接状态指示 + 明确失败原因 + 重试；V1.1：增加适配器兼容清单和购买引导（F-A-02）

### P5 · 诊断页（Diagnose）
- 大按钮"开始诊断"
- 进度：连接 → 读码 → 尝试读取车辆支持的冻结帧；Free 的专门冻结帧详情仍受 Pro 权益限制，但首次完整 AI 体验可使用已采集上下文
- 结果：故障码列表（代码 + 状态标签 + 通用含义）
- 冻结帧详情（Pro）：按 ECU + frame number 分组展示已支持 PID 的数值/单位；确定性阈值异常同时用图标、文字和颜色标注，不支持或缺失时不得伪造数据
- 每个 DTC 提供“Explain with AI”入口；Free 明确只能选择 1 个使用完整体验，优先推荐命中安全规则的代码，Pro 可选择多个并按每码独立状态排队（客户端并发最多 2）
- 发起前可选输入美国 ZIP/ZIP+4 以改善费用估算；默认不填也可继续，格式错误就地提示，ZIP 不写入普通日志/埋点
- 无故障码："未检测到故障码 ✅"
- 底部按钮：清除故障码（二次确认，F-B-02）

### P6 · AI 诊断结果页（核心页面）
- 顶部：故障码 + 严重程度大标签（🟢🟡🔴，F-C-03）
- "人话总结"段落（F-C-01）
- 可能原因列表（按概率，进度条）
- 维修费用估算（F-C-02）：低–高 + 地区，常驻显示 `AI estimate · not a quote`、`source=estimate` 与固定 estimate note
- DIY 步骤列表
- "何时找专业维修"
- 每个账号（含匿名账号）第 1 次 AI 诊断返回并展示完整结果，同时明确“已使用免费体验”
- 免费额度用尽后不请求受保护的 AI 内容：保留本地通用 DTC 含义并进入 P11；不得通过客户端遮罩持有未授权的完整结果
- 按钮：导出报告（Pro，F-G-01）；Free 点击进入 P11，不能先生成受保护 PDF 再遮罩
- 结果页常驻固定免责声明；免责声明不由 LLM 生成

### P7 · 实时数据页（Live Data）
- 仪表盘网格（默认：转速/车速/水温/电压）
- V1 Free 基础组：负荷、水温、燃油压力、转速、车速、进气温度、节气门、电压；数字/基础仪表显示并按车辆支持的 PID 自动降级
- V1 Pro 高级组：进气歧管压力、空气流量、OBD 标准、运行时间、MIL 距离/时间、燃油液位、大气压、环境/机油温度等 06 已定义且车辆声明支持的标准 PID；由统一 EntitlementGate 解锁
- V1.1：自定义布局（Pro，F-B-05）、图表模式、录制与回放（Pro，F-B-06）

### P8 · 历史（History）
- 诊断记录列表（按车辆分组/时间倒序）；Free 只展示最近 10 条，Pro 展示全部未删除历史
- 点击 → 查看历史 AI 诊断详情
- 搜索/筛选（故障码/车辆/日期）

### P9 · 保养（Maintenance）
- V1 为 Pro 页面；Free 进入时先展示权益说明和 P11，不允许只靠客户端绕过写入
- 保养时间线（F-D-03）
- 添加保养记录表单
- 保养计划设置（里程/时间间隔，F-D-04）；里程提醒根据用户更新的车库里程或保养记录重算，不显示“已从 OBD 自动读取总里程”

### P10 · 设置（Settings）
- 账号（登录/登出/导出数据/删除账号，F-E）
- 订阅管理（当前方案/升级/恢复购买，F-F-03）
- V1 通用：单位制（英/公）与英文；主题选择器（浅/深/跟随系统）在 V1.1 提供
- 免责声明 + 隐私政策 + 关于

### P11 · Paywall（订阅页）
- 价值主张（3 个 Pro 权益）
- V1 方案：年 $29.99（默认）/ 月 $4.99；“省 X%”必须由当前商店价格动态计算，不硬编码
- 7 天订阅试用只在 RevenueCat/商店返回 eligible 时展示；它与账号级 1 次 AI 免费体验是两套独立权益
- V1.1 增加单次 AI 解锁 $2.99；V1 不展示尚未实现的 OneTime 商品
- 恢复购买入口
- 隐私/条款链接

### P12 · 报告导出（Report）
- Pro 校验通过后才生成 PDF；预览 → 系统分享（邮件/信息/AirDrop）
- 费用区间始终标为 `AI estimate · not a quote`，页脚常驻固定免责声明
- 品牌化模板（logo + 配色）

## 3. 关键交互规范

| 交互 | 规范 |
|---|---|
| 连接失败 | V1：明确原因 + 一键重试；V1.1：再增加推荐适配器引导 |
| 读码中 | 进度指示，禁用操作按钮 |
| 清除故障码 | 弹窗确认："清除后若问题未解决，故障灯会重新亮起" |
| 订阅拦截 | 免费功能无感；Pro 功能触发 paywall；仅对商店判定 eligible 的用户标注“7 天免费试用” |
| 权益一致性 | 冻结帧详情、高级 PID、完整历史、第 2 辆车、保养与 PDF 全部复用同一 EntitlementGate；服务端写入仍以受控 RPC 的有效 Pro 复核为准 |
| 严重程度 | 全站统一颜色：🔴 #E53935 / 🟡 #FBC02D / 🟢 #43A047 |

AI 严重程度不能只依赖颜色或 emoji；必须同时显示文字标签、行动建议和 `can_drive` 说明。服务端确定性安全规则覆盖 LLM 输出时，UI 只展示覆盖后的最终值。

## 4. 设计规范（Design Tokens）

**色彩**（汽车科技感 + 可信赖）：
- 主色：`#0A84FF`（iOS 蓝）或品牌色（待定名后确认）
- V1 固定使用通过无障碍验收的深色主题；浅色与跟随系统 Token 可预留，但选择器和完整主题切换属于 V1.1
- 危险红 `#E53935`、警示黄 `#FBC02D`、正常绿 `#43A047`

**字体**：系统默认（SF Pro / Roboto），数字用等宽（tabular figures）显示仪表数据。

**组件风格**：圆角卡片（12px）、大按钮、留白充足——**明确对标 Torque Pro 做反设计**（Torque 是密密麻麻的仪表，我们做极简）。

---

## 5. 无障碍与合规

- 颜色对比度 ≥ WCAG AA
- 关键操作支持 VoiceOver / TalkBack
- 驾驶安全：已连接车辆且速度 PID > 0 时禁用清码、购买、设置和长文本交互；速度不可用时持续显示“停车后操作”提示，不为此强制申请 GPS 权限
- 免责声明在诊断结果页 + 报告 PDF 页脚常驻
- 不在客户端日志、埋点或崩溃报告中记录完整 VIN、车牌、ZIP code、AI Prompt 或自由文本保养备注

## 6. 埋点事件（关键）

| 事件 | 触发点 |
|---|---|
| `onboarding_completed` | 引导完成 |
| `connection_attempted` / `connection_succeeded` | 连接 |
| `diagnosis_completed` | 读码完成 |
| `ai_trial_consumed` | 首次完整 AI 免费体验成功落账 |
| `ai_diagnosis_viewed` / `ai_diagnosis_blocked` / `paywall_shown` / `subscribe_clicked` | AI 与转化漏斗 |
| `subscription_started` | 订阅成功 |
| `report_exported` | 导出报告 |
