## 1. 产品概述

**产品名**：AutoPilot AI（占位名，待定）

**一句话**：用 AI 把看不懂的汽车故障码翻译成人话，并告诉用户"可能是什么问题、修要多少钱、能不能继续开"。

**目标用户**：
- 美国 DIY 车主（25–55 岁）
- 二手车买家（验车场景）
- 有车家庭（日常健康监控）

**核心差异化**（相对 Torque Pro / Carly / Car Scanner）：
1. AI 诊断：故障码 → 人话解读 + 维修费用区间 + 严重程度 + DIY 步骤
2. 极简 UI：对比 Torque Pro 的复杂仪表盘
3. 价格便宜：对比 Carly 的高价订阅
4. 全连接支持：WiFi / BLE / 蓝牙经典三种适配器都支持

### 1.1 版本交付基线

| 优先级 | 交付版本 | 定义 |
|---|---|---|
| **P0** | **V1** | 首发必须完成，达到可测试、可审核、可双平台上架 |
| **P1** | **V1.1** | 上架后快速跟进的体验与商业化增强 |
| **P2** | **V2** | 社区、增长等长期生态能力 |

本文档描述完整产品蓝图，并按优先级分版本交付；每项功能的优先级即其交付版本。

### 1.2 权益基线

| 层级 | 权益 |
|---|---|
| **Free** | 标准连接与诊断、基础实时数据、VIN/排放就绪、账号云同步、1 辆车与基础历史；生命周期内 1 次完整 AI 诊断 |
| **Pro** | 免费 AI 次数用完后继续诊断；高级标准 PID/冻结帧、完整历史、无限车辆、保养和 PDF 报告 |
| **OneTime（V1.1 / P1）** | 非订阅用户 `$2.99` 解锁 1 次完整 AI 诊断，不属于 V1 上架范围 |

Free 的首次 AI 诊断不是删减版，必须返回与 Pro 相同的完整结果。服务端负责记录免费次数、订阅状态和额度；客户端只负责展示状态，不得自行判定放行。

## 2. 功能需求（完整清单）

### 模块 A · 连接与硬件（Connection）

#### F-A-01 适配器连接
- **描述**：支持三种连接方式连接 ELM327 兼容适配器。
  - WiFi 版（iOS 主力）：App 内引导连接适配器热点，TCP socket 通信
  - BLE 版（iOS）：BLE 4.0 扫描 + GATT 连接
  - 蓝牙经典版（Android 主力）：SPP 配对连接
- **用户故事**：作为车主，我要用我手上已有的适配器连接 App，以便读取车辆数据。
- **验收标准**：
  1. iOS 的 WiFi/BLE、Android 的 WiFi/BLE/蓝牙经典 SPP 均可成功建立连接并收发数据
  2. 连接失败时给出明确错误提示（超时/密码错误/适配器不支持）
  3. 支持记住上次连接方式，下次自动重连
  4. 连接状态实时显示（已连接/连接中/断开）
- **优先级**：P0 · **层级**：Free

#### F-A-02 适配器自动检测与推荐
- **描述**：App 内置适配器兼容清单；无法连接时，引导用户购买推荐适配器。
- **验收标准**：
  1. 内置适配器数据库（型号/连接方式/价格/购买链接）
  2. 检测失败时弹出"推荐适配器"引导页
  3. 购买链接带返佣追踪参数（affiliate）
- **优先级**：P1 · **层级**：Free

#### F-A-03 多协议支持
- **描述**：自动检测并支持 OBD2 主流协议。
  - ISO 15765-4（CAN 11/29 bit）
  - ISO 9141-2
  - ISO 14230-4（KWP2000）
  - SAE J1850（PWM / VPW）
- **验收标准**：
  1. 自动协议检测（AT SP 0）
  2. CAN、ISO 9141、KWP2000、J1850 的版本化 fixture/模拟器收发与解析测试全部通过；真实车辆矩阵至少覆盖可获得样本，并如实记录尚未取得的非 CAN 真车证据
  3. 协议检测失败时优雅降级并提示
- **优先级**：P0 · **层级**：Free

### 模块 B · 诊断核心（Diagnostics）

#### F-B-01 读取故障码（DTC）
- **描述**：读取标准 OBD2 排放相关 ECU 的故障码，显示代码 + 通用含义；厂商增强诊断不属于当前 P0 范围。
- **用户故事**：作为车主，故障灯亮了，我要知道是哪个故障码。
- **验收标准**：
  1. 正确解析并展示 DTC（如 P0420）及通用含义
  2. 区分 pending / confirmed / permanent 状态
  3. 标准响应包含 ECU 地址/模块信息时正确展示；ABS 等厂商增强模块不作为 V1 验收前提
  4. 读取失败/无故障码时给出友好提示
- **优先级**：P0 · **层级**：Free

#### F-B-02 清除故障码
- **描述**：清除 ECU 故障码（含二次确认，防止误操作）。
- **验收标准**：
  1. 清除前弹窗确认，提示"清除后若问题未解决故障灯会重新亮起"
  2. 清除成功/失败反馈
  3. 记录清除操作到历史
- **优先级**：P0 · **层级**：Free

#### F-B-03 冻结帧数据（Freeze Frame）
- **描述**：读取故障发生瞬间的车辆状态快照（转速、水温、车速、负荷等）。
- **验收标准**：
  1. 按 ECU + frame number 展示冻结帧各已支持 PID 及数值，不把不同来源覆盖或拼成一帧
  2. 用版本化的确定性阈值标注异常值（如故障时水温过高）；缺失/不支持时明确显示，不能让 LLM 猜测传感器值
- **优先级**：P0 · **层级**：Pro

#### F-B-04 实时数据流（Live Data）
- **描述**：实时显示车辆传感器数据；V1 使用数字值和基础仪表的固定网格，图表与自定义布局见 P1 的 F-B-05。
- **验收标准**：
  1. Free 基础组：负荷、水温、燃油压力、转速、车速、进气温度、节气门、电压；Pro 高级组为 06 已定义的其余标准 PID，均只读取车辆声明支持的项目
  2. CAN 场景下基础页面聚合有效采样目标 ≥ 5 samples/s；每个 PID 的实际刷新率受串行 ELM327、已选 PID 数量与适配器能力约束并如实显示采样时间
  3. 数值异常时高亮提示（如水温 > 110°C）
  4. V1 支持数字和基础仪表两种显示；图表与自定义布局不作为 P0 验收项
- **优先级**：P0 · **层级**：Free（基础 PID）/ Pro（高级 PID）

#### F-B-05 自定义仪表盘
- **描述**：用户自定义组合仪表盘布局（拖拽 PID、选择显示样式、保存多套布局）。
- **验收标准**：
  1. 支持添加/删除/拖拽 PID 组件
  2. 支持仪表盘（gauge）/ 数字 / 图表三种组件样式
  3. 支持保存多个布局并切换
- **优先级**：P1 · **层级**：Pro

#### F-B-06 数据记录与回放
- **描述**：录制实时数据流，支持回放和导出（CSV）。
- **验收标准**：
  1. 一键开始/停止录制
  2. 录制文件本地保存 + 可选云同步
  3. 回放带时间轴
  4. 导出 CSV 供 Excel/分析工具使用
- **优先级**：P1 · **层级**：Pro

#### F-B-07 排放就绪状态（I/M Readiness）
- **描述**：显示排放系统各监测项的就绪状态，为美国 smog 检测前准备提供参考，但不保证实际检测结果。
- **验收标准**：
  1. 显示各监测项（催化器、氧传感器、EVAP 等）的 Ready / Not Ready / N/A 状态
  2. 根据就绪状态给出检测前准备提示，同时明确“不能据此保证通过 smog 检测”
  3. 对未就绪项只提供通用准备原则；只有命中已验证的车型资料时才展示厂商特定 drive cycle，并始终提示以当地检测机构结果为准
- **优先级**：P0 · **层级**：Free

#### F-B-08 VIN 识别
- **描述**：通过 OBD2 读取车辆 VIN（模式 09），解码出年份/品牌/型号/发动机。
- **验收标准**：
  1. 自动读取 VIN 并解码显示车辆信息
  2. 支持手动输入 VIN 兜底
  3. 解码信息存入车辆档案
- **优先级**：P0 · **层级**：Free

### 模块 C · AI 诊断（AI Diagnosis）— 核心差异化

#### F-C-01 故障码 AI 解读
- **描述**：将故障码 + 车辆信息 + 冻结帧数据输入 LLM，生成人话解读。
- **输出结构**：字段与类型以 `07-AI-DIAGNOSIS.md` 的最终契约为唯一依据；V1 合法响应示例如下（严格 JSON）：
  ```json
  {
    "schema_version": "1.0",
    "dtc": "P0420",
    "summary": "催化转化器效率低于阈值，通常不影响短途行驶，但会导致排放超标。",
    "severity": "warning",
    "severity_label": "尽快检查",
    "possible_causes": [
      {"cause": "催化转化器老化失效", "probability": 0.6},
      {"cause": "后氧传感器故障", "probability": 0.25},
      {"cause": "排气管泄漏", "probability": 0.15}
    ],
    "repair_cost": {
      "low": 800,
      "high": 1800,
      "currency": "USD",
      "labor": {"low": 150, "high": 400},
      "parts": {"low": 650, "high": 1400},
      "source": "estimate",
      "estimate_note": "基于车辆信息和通用美国市场数据的粗略估算，不是维修厂报价。"
    },
    "parts": [
      {
        "name": "催化转化器",
        "price_range": {"low": 650, "high": 1400},
        "oem_or_aftermarket": "aftermarket"
      }
    ],
    "diy_steps": ["检查后氧传感器读数", "检查排气管有无泄漏"],
    "when_to_seek_pro": "若伴随动力下降或油耗明显增加，建议尽快送修。",
    "can_drive": true,
    "can_drive_note": "可短途驾驶，但持续驾驶可能导致排放测试失败。",
    "disclaimer": "AI 诊断仅供参考，不替代认证技师的现场检查；如有安全风险，请立即停车并寻求专业帮助。"
  }
  ```
- **验收标准**：
  1. 客户端先同步诊断/DTC，服务端按记录 ID 加载 DTC、车辆和冻结帧 → 返回通过 07 定义的 zod schema 校验的结构化解读
  2. `severity`、`can_drive` 与行动建议遵守 07 的严重程度硬规则
  3. `possible_causes` 按概率排序且概率和为 1
  4. V1 的维修费用为美国市场 AI 估算，`repair_cost.source` 必须为 `estimate`
  5. Free 用户首次诊断与 Pro 返回相同完整字段；免费次数用完后由服务端要求有效订阅
  6. schema 校验失败自动重试 1 次，仍失败则返回可恢复的错误
  7. 正常上游条件下服务端端到端响应 p95 < 5 秒；超时/上游不可用按 04 的可恢复错误返回且不消耗额度
- **优先级**：P0 · **层级**：Free（完整 1 次）/ Pro（之后按服务端额度）

#### F-C-02 维修费用估算
- **描述**：V1 由 LLM 生成美国市场维修费用估算区间（工时 + 配件）；ZIP code 可作为上下文，但不构成专业数据报价。
- **验收标准**：
  1. 支持可选 ZIP code；未提供时仍能返回美国市场估算
  2. 返回总价、工时费、配件费区间和 USD 币种
  3. V1 固定标注 `source: "estimate"`，UI 明示“AI estimate, not a quote”
  4. RepairPal / Motor 等专业数据接入后方可使用对应来源名，供应商选型不阻塞 V1
- **优先级**：P0 · **层级**：Free（随完整 1 次 AI 诊断）/ Pro（之后）

#### F-C-03 严重程度分级与行动建议
- **描述**：明确告诉用户"能不能继续开"。
- **验收标准**：
  1. 三档：🟢 可继续开 / 🟡 尽快检查 / 🔴 立即停车
  2. 每档有明确的行动建议
- **优先级**：P0 · **层级**：Free（随完整 1 次 AI 诊断）/ Pro（之后）

#### F-C-04 历史诊断记录
- **描述**：保存每次诊断结果，支持查看历史、对比同一故障码的变化。
- **验收标准**：
  1. 诊断记录自动保存（含时间、诊断时用户录入的里程快照〔未知时明确标记〕、故障码、解读结果）
  2. 按车辆分组查看历史
  3. 支持搜索和筛选
  4. Free 展示最近 10 条，Pro 展示全部未删除历史；权益变化不删除设备上属于用户的原始诊断数据
- **优先级**：P0 · **层级**：Free（保存）/ Pro（完整历史）

### 模块 D · 车辆管理（Garage）

#### F-D-01 多车管理（车库）
- **描述**：管理多辆车的档案，切换当前车辆。
- **验收标准**：
  1. 添加/编辑/删除车辆
  2. 车辆列表展示（品牌/型号/年份/里程）
  3. 支持切换当前活动车辆
  4. 第 2 辆车及以上由统一 Pro entitlement 校验；服务端创建入口不能只信客户端开关
- **优先级**：P0 · **层级**：Free（最多 1 辆）/ Pro（无限）

#### F-D-02 车辆档案
- **描述**：完整车辆信息（VIN 解码 + 手动补充）。
- **验收标准**：
  1. 展示：品牌、型号、年份、发动机、变速箱、用户录入的里程、可选车牌
  2. VIN 自动解码填充
  3. 手动编辑补充
- **优先级**：P0 · **层级**：Free

#### F-D-03 保养记录
- **描述**：记录保养历史（机油、刹车、轮胎等）。
- **验收标准**：
  1. 添加保养记录（项目/日期/里程/费用/备注）
  2. 保养历史时间线展示
- **优先级**：P0 · **层级**：Pro

#### F-D-04 保养提醒
- **描述**：按里程/时间自动提醒保养。
- **验收标准**：
  1. 预设保养周期（机油 5000mi / 刹车 25000mi 等，可自定义）
  2. 到期推送本地通知
  3. 用户更新车库里程或新增带里程的保养记录时重新计算提醒；标准 OBD 不承诺自动读取车辆总里程
- **优先级**：P0 · **层级**：Pro

### 模块 E · 账号与云（Account & Cloud）

#### F-E-01 注册/登录
- **描述**：首次使用创建匿名会话，可继续以游客身份使用；之后支持邮箱、Apple、Google 登录并绑定匿名会话数据。
- **验收标准**：
  1. 首次启动可创建并恢复匿名会话，无需注册即可进入 Free 流程
  2. 邮箱、Apple、Google 三种登录方式均可
  3. 匿名用户登录/注册后，车辆、诊断历史和免费 AI 使用次数原子绑定到正式账号，不重复发放免费权益、不丢数据
  4. 绑定完成后云同步自动启用，失败时保留匿名本地数据并允许重试
  5. V1 首次安装需要一次网络连接以创建/恢复匿名身份并初始化该用户的加密本地库；完成后本地 OBD 诊断可离线使用
- **优先级**：P0 · **层级**：Free

#### F-E-02 云同步
- **描述**：车辆、诊断历史、设置跨设备同步。
- **验收标准**：
  1. 登录后数据自动上传/下载
  2. 更新携带上次同步的服务端版本；冲突时拉取双方版本并提示合并，不能用不可信的设备时间直接覆盖云端
  3. 离线时写入本地 outbox，联网后幂等同步；软删除 tombstone 也必须同步
- **优先级**：P0 · **层级**：Free

#### F-E-03 数据导出与删除
- **描述**：导出个人数据 / 删除账号（合规 GDPR/CCPA）。
- **验收标准**：
  1. V1 可一键导出全部数据（版本化 JSON）；CSV 等增强格式属于 V1.1
  2. 一键删除账号及云端数据
- **优先级**：P0 · **层级**：Free

### 模块 F · 订阅与支付（Subscription）

#### F-F-01 订阅方案
- **描述**：月订阅 $4.99 / 年订阅 $29.99；仅对商店判定 eligible 的用户展示 7 天免费试用。
- **验收标准**：
  1. RevenueCat 集成，双平台支付
  2. 以 App Store / Google Play 经 RevenueCat 返回的 eligibility 与商品信息为准：eligible 用户展示 7 天试用，非 eligible 用户不得显示或承诺试用
  3. 订阅状态实时同步（App 内 + 服务端校验）
  4. 用户可先完成 1 次无需订阅的完整 AI 诊断；次数用完后 AI 端点要求有效 Pro 权益
- **优先级**：P0 · **层级**：Pro

#### F-F-02 单次解锁（OneTime）
- **描述**：V1.1 为低频用户提供单次 AI 诊断解锁 $2.99；不属于 V1/P0 上架范围。
- **验收标准**：
  1. 非订阅用户可选择单次解锁
  2. 单次解锁仅本次诊断有效
- **优先级**：P1 · **层级**：OneTime

#### F-F-03 恢复购买与订阅管理
- **描述**：恢复购买、查看/取消订阅、账单管理。
- **验收标准**：
  1. Restore Purchases 可用
  2. 订阅管理入口（跳转商店订阅页）
  3. 订阅到期/取消后的降级逻辑
- **优先级**：P0 · **层级**：Free
